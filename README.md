# 🌐 Personal Portfolio Website

A responsive personal portfolio website created to showcase my **skills, projects, education, resume, and contact information**.

The website is built using HTML and CSS with a clean and simple design focused on presenting my profile and development work.

## ✨ Features

* 👩‍💻 About Me section
* 🎓 Education details
* 🛠️ Skills section
* 📂 Project highlights
* 📄 Resume section
* 📱 Responsive layout
* 🔗 Contact and social links

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts

## 📁 Project Structure

```text
portfolio-website/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 Getting Started

To view the website locally:

1. Clone the repository:

```bash
git clone https://github.com/vaibhaviboche/portfolio-website.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.
